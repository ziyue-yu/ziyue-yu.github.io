第 0 章

案例设定:一位患者 = 一个矩阵

整份教程只围绕一个研究问题展开:

给定患者 $p$ 的时序电子病历 $X_p \in \mathbb{R}^{T\times F}$,学习一个表征 $h_p \in \mathbb{R}^d$,用于疾病预测。

其中 $T$ = 时间步数(如住院后 48 小时,每小时一次记录),$F$ = 医疗特征数。教程中固定使用 $F=3$ 的三个特征:

特征记号单位正常参考
血糖 Glucose$x_G$mg/dL70–140
心率 HR$x_H$bpm60–100
收缩压 BP$x_B$mmHg90–120

于是一位患者 4 个时刻的记录就是:

X_p = [250 120 90] ← t=1(入院,高糖、心动过速、低血压) [230 110 95] ← t=2 [180 95 105] ← t=3(治疗起效) [150 85 110] ← t=4(趋于稳定)
为什么这个案例适合学线性代数?因为患者表征学习的每一步都精确对应一个线性代数概念:某时刻的状态 = 向量;整个病程 = 矩阵;队列 = 张量;特征缩放 = 对角矩阵;特征共变 = 协方差矩阵;特征交互 = 注意力矩阵;患者压缩表征 = 低秩投影。学完线性代数,你就同时拆解了一篇 RETAIN / Transformer-EHR 类论文的全部数学结构。
严谨性提示(队列张量):把队列写成 $\mathcal{X}\in\mathbb{R}^{N\times T\times F}$ 隐含所有患者 $T$ 相同。真实 EHR 中各患者长度 $T_p$ 不同,实际是 padding + mask(补齐到 $T_{max}$ 并用掩码标记有效位,第 3 章)或事件序列表示。本教程为教学统一用等长 $T$。
第 1 章

向量:某一时刻的"患者状态快照"

1.1 状态向量

某一时刻 $t$,患者的三个测量值构成一个列向量:

$$\mathbf{x}_t = \begin{pmatrix}250\\120\\90\end{pmatrix}\begin{matrix}\leftarrow\text{Glucose}\\\leftarrow\text{HR}\\\leftarrow\text{BP}\end{matrix}$$
现实意义:这个向量就是"患者此刻的状态"在 3 维医学空间中的坐标。健康人群聚集在这个空间的某个区域(正常值立方体 $[70,140]\times[60,100]\times[90,120]$ 附近),病情恶化常常表现为状态向量远离这个区域。注意:正常参考区间并不是欧氏空间里的"病情原点" —— 临床上偏离的方向(高糖 vs 低血糖)往往比距离本身更有意义,这个几何模型只是有用的近似。"疾病预测"本质上就是判断患者轨迹正在朝哪个危险区域移动。

1.2 向量的模长:偏离正常有多远

以正常值中心 $c = (105, 80, 105)^\top$ 为参考,偏移向量 $\mathbf{x}_t - c$ 的 L2 范数度量"整体异常程度":

演算:t=1 与 t=4 的异常程度对比
t=1: $x_1 - c = (145, 40, -15)$,$\|x_1-c\|_2 = \sqrt{145^2+40^2+15^2} = \sqrt{21025+1600+225} = \sqrt{22850} \approx \mathbf{151.2}$
t=4: $x_4 - c = (45, 5, 5)$,$\|x_4-c\|_2 = \sqrt{2025+25+25} = \sqrt{2075} \approx \mathbf{45.6}$
结论:异常度从 151.2 降到 45.6 —— 一个标量就概括了"病情好转"。注意陷阱:血糖(单位 mg/dL,数值上百)主导了这个距离,心率的变化几乎被淹没 —— 这就是第 7 章必须做标准化的原因。

1.3 单位换算的坑:量纲 = 坐标轴的刻度

量纲是向量空间的"隐形坐标刻度"。血糖从 mg/dL 换成 mmol/L(÷18),等价于把该坐标轴压缩 18 倍 —— 向量空间本身没变,但所有基于距离的算法(KNN、L2 正则、梯度尺度)结果全变。医疗数据多源异构(不同医院单位不同),这是 EHR 研究中最常见的静默 bug 来源。
第 2 章

向量代数:加减、线性组合、张成与正交

2.1 向量减法:状态变化量

两个时刻状态向量相减,得到"状态变化向量"(state change vector):

演算:治疗前后对比
Δx = x₄ − x₁ $= (150,85,110) - (250,120,90) = (-100, -35, +20)$
解读:血糖降 100、心率降 35、血压升 20。严谨地说,Δx 是状态变化;只有当两个时点具有明确的治疗语义(给药前/后)且排除其他干扰时,它才可以被解读为"治疗反应" —— 观察性数据中变化 ≠ 治疗效果(混杂)。在学到的表征空间里,$h_{治疗后} - h_{入院}$ 如果跨患者指向一致方向,那个方向就是"好转轴" —— 这正是 word2vec 语义算术(king − man + woman ≈ queen)在患者表征上的翻版。

2.2 线性组合:临床评分卡的本质

$c_1x_1 + c_2x_2 + \cdots + c_F x_F = \mathbf{w}^\top\mathbf{x}$ —— 所有线性临床评分都是它:

演算:一个简易风险评分(NEWS 评分的精神)
权重 w = (0.5, 2.0, 1.5)(标准化后的血糖、心率、血压权重):
患者 x' = (2.17, 1.75, −1.00)
评分 = w·x' $= 0.5\times2.17 + 2.0\times1.75 + 1.5\times(-1.00) = 1.085 + 3.5 - 1.5 = \mathbf{3.09}$
视角升级:人工评分卡 = 医生手工设定的 $w$;逻辑回归 = 从数据学出 $w$;深度模型 = 学出多层嵌套的线性组合。你每天都在用的"加权求和",就是线性组合。

2.3 张成与线性无关:特征到底有没有冗余

  • 张成(span):一组特征所有线性组合能到达的空间 —— 3 个特征的评分卡最多只能"看到" $\mathbb{R}^3$ 中由它们张成的部分;
  • 线性相关:若某特征能被其他特征线性表出,它携带零新信息。医疗数据的典型:肌酐与 eGFR(eGFR 由肌酐、年龄、性别公式算出)、体温 ℃ 与 ℉、由检验套餐重复采的指标;
  • 后果:特征矩阵秩亏 → $X^\top X$ 不可逆 → 线性回归解不唯一、系数符号乱飞(第 8 章详算)。

2.4 正交:特征之间"零重叠"(有条件)

$\mathbf{a}\cdot\mathbf{b} = 0 \iff$ 正交。严格的对应关系是:对已中心化的数据列,零内积 ⇔ 零 Pearson 协方差(因为此时 $\mathrm{cov}(a,b) \propto a^\top b$)。少了中心化这个前提,"正交 = 不相关"不成立。

现实意义:①正交特征信息不重叠,但不能反推"理想特征集必须互相正交" —— 医学中高度相关的变量(如血糖与胰岛素)常共同携带重要信息,是否剔除冗余取决于共线性程度与任务(第 8 章);②神经网络的正交初始化让权重矩阵的行彼此正交,前向时各方向能量不互相挤压,缓解梯度消失(第 6 章验算);③注意力各头学到相似模式是常见冗余,可以用 diversity regularization(如鼓励头间正交的罚项)缓解 —— 但正交不是 Transformer 的内在数学要求;④第 10 章 PCA 的主成分两两正交 —— 这是"主成分彼此不冗余"的代数保证(由协方差矩阵对称性推出)。
第 3 章

相似度:寻找"相似患者"

2.1 点积与余弦相似度的患者检索意义

患者队列研究、病例对照匹配(case-control matching)、「像我这样的患者预后如何」—— 都是在问:哪些患者的状态向量方向一致?

$$\cos(\mathbf{x}_a, \mathbf{x}_b) = \frac{\mathbf{x}_a\cdot\mathbf{x}_b}{\|\mathbf{x}_a\|\,\|\mathbf{x}_b\|}$$
演算:三位入院患者,谁和谁病情模式相似?
标准化后(第 7 章方法,z-score)的入院向量:
P1 = (2.0, 1.5, -1.0) —— 高糖+心动过速+低血压
P2 = (1.8, 1.6, -0.9) —— 同模式,程度稍轻
P3 = (-0.5, 1.2, 0.8) —— 心率快但血糖偏低、血压偏高(不同病因)
P1·P2 $= 2.0\times1.8 + 1.5\times1.6 + (-1.0)(-0.9) = 3.6+2.4+0.9 = 6.9$
$\|P1\| = \sqrt{4+2.25+1} = 2.69$,$\|P2\| = \sqrt{3.24+2.56+0.81} = 2.57$
$\cos(P1,P2) = 6.9/(2.69\times2.57) = \mathbf{0.998}$ —— 几乎同向,同种病情模式 ✓
P1·P3 $= -1.0+1.8-0.8 = -1.0$;$\|P3\| = \sqrt{0.25+1.44+0.64} = 1.53$
$\cos(P1,P3) = -1.0/(2.69\times1.53) = \mathbf{-0.24}$ —— 不同模式 ✓
现实意义:这就是"相似患者检索"(patient similarity retrieval)的最小实现。真实系统用学到的表征 $h_p$(而非原始测量)做同样计算 —— 表征学习的全部目标,就是让"临床结局相似"的患者在向量空间中彼此靠近。
交互演示:患者相似度检索

目标患者 P1 固定为"高糖+快心率+低血压"模式。调节候选患者 P2 的各特征偏离度,观察余弦相似度与欧氏距离的变化 —— 注意两者给出"相似"判断的差异。

2.2 缺失值:医疗数据的常态

真实 EHR 中某时刻可能只测了心率,血糖缺失。对应到向量:某些分量"不存在"。处理方式本身就是矩阵操作:

  • 掩码向量 $m_t = (1, 1, 0)^\top$(0 = 缺失),数据向量与掩码逐元素相乘(Hadamard 积) $x_t \odot m_t$ 把缺失位置零;
  • 相似度只在 $m_a \odot m_b$ 的共同观测维度上计算;
  • GRU-D 等模型把 $m_t$ 和时间间隔 $\Delta_t$ 一起作为输入 —— 缺失模式本身携带信息(没测血糖 ≈ 医生认为血糖不重要 ≈ 病情不重)。
第 4 章

范数、正则化与梯度裁剪:从 300 项指标到 3 项

4.1 Lp 范数家族与医疗角色

$$\|\mathbf{x}\|_p = \left(\sum_i |x_i|^p\right)^{1/p}$$
范数公式在患者数据中的角色
L1(曼哈顿)$\sum_i|x_i|$L1 正则(LASSO)→ 自动特征选择:从 300 项检验指标中把绝大多数系数压成精确的 0,只留下少数关键指标 —— 产出可解释的"最小指标集",临床医生最爱
L2(欧氏)$\sqrt{\sum_i x_i^2}$L2 正则 / weight decay:系数小而平滑,小队列(几百例患者)防过拟合的主力;异常度度量(第 1 章)
L∞(最大)$\max_i|x_i|$最坏情况扰动:对时序 EHR 可表示每个变量允许的最大篡改幅度 $\|\delta\|_\infty\le\epsilon$(对抗鲁棒性/数据投毒分析的预算);"最异常的那个指标有多异常"

4.2 正则化的几何:L1 为什么产稀疏

给损失加罚项 $\lambda\|w\|_p$ 等价于把 $w$ 约束在"p 范数球"内,最优解出现在损失等高线与球面的切点。L1 的球是菱形,尖角落在坐标轴上 —— 切点大概率撞上尖角,此时某些分量精确为 0 → 稀疏 → 特征被自动剔除。L2 的球是光滑圆,切点位置随机,系数都变小但几乎不为 0。对 EHR 研究:L1 = "只保留关键指标"的数学装置。
交互演示:p-(准)范数等高线 —— 稀疏性的几何来源

所有满足 ‖w‖p=1 的点。p=1 是菱形(尖角在轴上 → 稀疏),p=2 是圆,p→∞ 是方形。想象损失等高线从外向内收缩,最先碰到哪里?

(0.5 → 星形 · 1 → 菱形 · 2 → 圆 · 8 → 接近方形)

⚠ 严格性提示:0<p<1 时不满足三角不等式,不是范数,只是 quasi-norm(准范数)等高线 —— 演示形状可以,叫 "Lp norm ball" 不行。只有 p≥1 才是真正的范数。

4.3 距离家族:患者相似度的三种尺子

  • 欧氏 $\|a-b\|_2$:整体偏离程度,但对量纲敏感(第 1 章的坑);
  • 曼哈顿 $\|a-b\|_1$:高维下对比度更好,对离群测量(一次误测的极端血糖)更鲁棒;
  • 余弦距离 $1-\cos\theta$:看"模式"不看"程度"(第 3 章)。

4.4 矩阵范数与梯度裁剪

Frobenius 范数 $\|A\|_F = \sqrt{\sum_{i,j}a_{ij}^2}$ 把矩阵拉直当向量算 L2。训练时若总梯度范数超阈值就整体缩放:

$$\text{若 } \|\mathbf{g}\|_2 > \tau,\quad \mathbf{g} \leftarrow \mathbf{g}\cdot\frac{\tau}{\|\mathbf{g}\|_2}$$
医疗场景的特殊性:EHR 存在极端值(一次误录的血糖 2000、罕见危重事件),单个样本可能产生巨大梯度,一步更新毁掉整晚训练。梯度裁剪(通常 τ=1.0)是不改变方向、只缩短步长的"保险丝" —— 医疗大模型和时序模型训练的标配。
第 5 章

矩阵乘法:患者队列的批量变换机器

5.1 逐格演算:每个格子 = 一次点积

$(AB)_{ij}$ = A 的第 i 行 · B 的第 j 列;内维必须相等 $(m\times k)(k\times n)\to(m\times n)$。

演算:3 位患者 × 3 特征,一次算出所有人的"双指标风险分"
标准化数据 X(3 患者 × 3 特征),权重 W(3 特征 × 2 个评分):
X = [2.0 1.5 -1.0] P1 W = [0.5 0.1] ← 血糖 [0.5 0.5 0.5 ] P2 [ 2.0 0.3] ← 心率 [-0.5 -1.0 1.0 ] P3 [1.5 2.0] ← 血压 W 第 1 列 = 代谢应激评分权重,第 2 列 = 循环评分权重
P1 的代谢评分 (1,1) 格 = X 第 1 行 · W 第 1 列 = $2.0\times0.5 + 1.5\times2.0 + (-1.0)\times1.5 = 1.0+3.0-1.5 = \mathbf{2.5}$
全部算完:
Y = XW = [2.5 -1.35] P1:代谢 2.5,循环 −1.35(低血压拉低) [ 2.0 1.2 ] P2 [-0.75 1.65] P3 验证 (1,2):$2.0\times0.1 + 1.5\times0.3 + (-1.0)\times2.0 = 0.2+0.45-2.0 = -1.35$ ✓; 验证 (2,1):$0.5\times0.5+0.5\times2.0+0.5\times1.5 = 0.25+1.0+0.75 = 2.0$ ✓
batch 的意义:不用矩阵,3 位患者要循环 3 次;写成 XW,GPU 一次算完 10 万患者的全部评分,每个格子独立并行。把 for 循环变成矩阵乘法,是医疗模型能全院部署的工程根基。

5.2 一层神经网络 = 仿射变换

$y = Wx + b$:旋转、拉伸(由 W)再平移(由 b)。深度网络 = 多个仿射变换嵌套非线性,$W_L\cdots W_2W_1x$ 把"原始指标空间"逐步弯折成"风险可分空间"。

5.3 转置与不可交换:顺序就是医学流程

演算:先标准化再嵌入 ≠ 先嵌入再标准化
$AB \neq BA$:变换有顺序。医疗数据管线里,"先标准化(z-score)再做嵌入投影"是唯一正确顺序 —— 反过来等价于在未校准量纲的空间里学嵌入,血糖(上百)会主导一切。
转置规则 $(AB)^\top = B^\top A^\top$(顺序反转):反向传播推导梯度维度时全靠它;注意力里 $K^\top$ 让"特征×维度"转回"维度×特征"才能和 Q 做点积。
交互演示:矩阵 = 特征空间变形器

把 (血糖, 心率) 平面交给 2×2 矩阵 M 变形。红/蓝箭头是特征向量(只被缩放、不被旋转的方向,λ 为特征值)—— 第 10 章 PCA 找的就是对称矩阵的这些方向。

第 6 章

特殊矩阵家族:患者建模的六种武器

矩阵定义在患者表征学习中的角色
单位矩阵 $I$对角全 1;$Ix=x$残差连接 $y = x + f(x)$ 的矩阵视角:梯度有"直通车道",深网络可训练
对角矩阵仅对角非零标准化 $D^{-1}$(第 7 章)、时间衰减 $\Gamma$(第 7 章)、Adam 优化器的逐参数学习率 $1/\sqrt{\hat v}$ 就是时变对角阵
对称矩阵 $A=A^\top$关于主对角线镜像协方差矩阵 $\Sigma$、Hessian、Gram 矩阵 $X^\top X$ —— 对称保证特征值为实数、特征向量正交(PCA 合法性的来源)
正交矩阵 $Q^\top Q=I$列向量两两正交且单位长保长度、保夹角 → 正交初始化防梯度消失;RoPE 位置/时间编码 = 按位置旋转 Q/K 向量;SVD 的 U、V
置换矩阵 $P$每行每列恰一个 1打乱患者顺序(shuffle 训练集);多头注意力拼接后的维度重排
半正定 $A\succeq 0$任意 x 有 $x^\top Ax \ge 0$协方差矩阵必半正定(任何方向投影的方差 ≥ 0)→ PCA 特征值非负;Hessian 在驻点正定 ⇒ 严格局部极小(注意:仅半正定不足以判定,见第 17 章)
演算:验证旋转矩阵是正交矩阵(保长度)
$Q = \begin{pmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{pmatrix}$,θ=90°:$Q=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$
$Q^\top Q = \begin{pmatrix}0&1\\-1&0\end{pmatrix}\begin{pmatrix}0&-1\\1&0\end{pmatrix} = I$ ✓
保长度:$\|Q(3,4)^\top\| = \|(-4,3)\| = 5 = \|x\|$ ✓ —— 旋转不改尺度,这就是"正交初始化保持梯度能量"与"RoPE 只转方向、不改语义强度"的原理。
为什么协方差必为半正定:任意权重方向 w 上,患者评分的方差 $\mathrm{Var}(Xw) = w^\top\Sigma w$ 不可能是负数 —— 方差非负 ⇒ Σ 半正定 ⇒ 特征值非负 ⇒ PCA 的"解释方差占比"永远是合法百分比。一条从定义直通论文图表的推理链。
第 7 章

矩阵变换:标准化、嵌入与时间加权

7.1 标准化 = 对角矩阵缩放

第 1 章发现血糖数值主导距离。解法是 z-score 标准化:$x' = (x-\mu)/\sigma$。写成矩阵形式,对整个数据矩阵:

$$X' = (X - \mathbf{1}\mu^\top)\,D^{-1}, \qquad D = \mathrm{diag}(\sigma_G, \sigma_H, \sigma_B)$$
演算:对角矩阵右乘 = 逐列缩放
队列统计:$\mu = (120, 85, 105)$,$\sigma = (60, 20, 15)$
入院向量 x = (250, 120, 90) 标准化:
血糖:$(250-120)/60 = 2.17$;心率:$(120-85)/20 = 1.75$;血压:$(90-105)/15 = -1.00$
$x' = (2.17, 1.75, -1.00)$ —— 三个特征现在同尺度,心率的影响不再被血糖淹没 ✓
矩阵视角:右乘 $D^{-1} = \mathrm{diag}(1/60, 1/20, 1/15)$ 把每列除以对应 $\sigma$。对角矩阵的几何意义 = 沿坐标轴各向异性缩放,它不改变数据的"形状结构",只校准刻度。

3.2 特征嵌入 = 投影矩阵

把 F=3 维原始特征投到 d 维表征空间(如 d=4):$E = XW_e$,$W_e \in \mathbb{R}^{3\times 4}$。

现实意义:为什么要升维?3 维空间里"血糖高 + 心率快 + 血压低"这个组合模式只是某个方向;升到高维后,表示空间有了更大的容量(capacity)去编码复杂的特征组合 —— 注意这是"提供了可能",至于"休克前期模式"是否真的占据一个可分离的方向,是训练学到的结果,不是维度升高自动保证的。$W_e$ 的第 i 行回答:"原始特征 i 应该向哪些表征方向贡献能量"。

3.3 时间衰减加权 = 对角矩阵左乘

直觉:3 天前的测量不如 1 小时前的重要。给每个时间步一个权重 $\gamma_t = e^{-\Delta_t/\tau}$,写成对角矩阵 $\Gamma = \mathrm{diag}(\gamma_1,\dots,\gamma_T)$,则加权轨迹 = $\Gamma X$。

演算:τ = 24h 的指数衰减
距当前 $\Delta = (72, 48, 24, 1)$ 小时 → $\gamma = (e^{-3}, e^{-2}, e^{-1}, e^{-0.04}) \approx (0.050, 0.135, 0.368, 0.961)$
加权后,最早时刻的信息只剩 5%。左乘对角矩阵 = 逐行缩放(对比:右乘 = 逐列)。行 ↔ 时间,列 ↔ 特征,这条对应关系请牢记,后面注意力矩阵的解读全靠它。
从左乘/右乘看矩阵乘法:$\Gamma X$ 作用在"时间轴",$X D^{-1}$ 作用在"特征轴"。一个 $T\times F$ 患者矩阵,左边乘 $T\times T$ 矩阵 = 混合/加权时刻,右边乘 $F\times F$ 矩阵 = 混合/加权特征。第 12 章的特征注意力 $AV$ 则是左乘思想的数据驱动版本:在"token × 维度"布局下,$F\times F$ 的 $A$ 从左侧混合 value 矩阵的行(特征 token),与 $\Gamma X$ 混合时刻同构 —— 区别在于 $\Gamma$ 是先验固定的对角阵,而 $A$ 是由 $QK^\top$ 从数据本身实时算出的、依赖输入的全连接矩阵。"固定的线性变换"与"数据依赖的线性变换"这一区分,正是 attention 的本质。
第 8 章

秩、行列式与线性方程组:信息是否够、解是否存在

8.1 秩:特征矩阵里"真正有用的信息量"

秩 = 线性无关行(列)的最大个数 = 变换后空间的维度。

演算:三个数据矩阵的命运
$A_1=\begin{pmatrix}1&2\\3&4\end{pmatrix}$:两行不成比例 → rank=2(满秩),两个特征都有独立信息
$A_2=\begin{pmatrix}1&2\\2&4\end{pmatrix}$:第 2 列 = 第 1 列 × 2 → rank=1。想象列 1 是体温 ℃、列 2 是换算后的 ℉×0.05 —— 名义上 2 个特征,实际 1 份信息,平面被压成一条线(信息塌缩)
医疗实例:肌酐、由公式算出的 eGFR、尿素氮同时入模 —— eGFR 几乎是其他变量的确定性函数,特征矩阵接近秩亏,回归系数会变得极不稳定(符号反直觉、置信区间巨大)。诊断:算秩 / 条件数;治疗:删冗余特征或加正则。

8.2 行列式:变换的"面积缩放率"

$\det\begin{pmatrix}a&b\\c&d\end{pmatrix} = ad-bc$;$|\det|$ = 面积放大倍数;$\det = 0 \iff$ 压扁 ⇔ 不可逆。

演算
$A_1$:det $= 4-6 = -2$ → 面积 ×2(负号=镜像),可逆 ✓;$A_2$:det $= 4-4 = 0$ → 压扁,不可逆 ✓(与秩的判断一致)

8.3 逆矩阵与最小二乘:从数据反推评分权重

$A^{-1}$ 是"撤销"变换的矩阵。线性回归的解析解 —— 正规方程:$\hat\beta = (X^\top X)^{-1}X^\top y$

演算:用心率预测住院天数(3 位患者)
数据:$X = \begin{pmatrix}1&70\\1&90\\1&110\end{pmatrix}$(第 1 列截距,第 2 列入院心率),y = (3, 5, 7) 天
$X^\top X = \begin{pmatrix}3&270\\270&25100\end{pmatrix}$,$X^\top y = \begin{pmatrix}15\\1430\end{pmatrix}$
(25100 = 70²+90²+110² = 4900+8100+12100;1430 = 70×3+90×5+110×7)
求逆:det $= 3\times25100 - 270^2 = 75300-72900 = 2400$
$(X^\top X)^{-1} = \frac{1}{2400}\begin{pmatrix}25100&-270\\-270&3\end{pmatrix}$
解:$\hat\beta_0 = \frac{25100\times15 - 270\times1430}{2400} = \frac{376500-386100}{2400} = \frac{-9600}{2400} = -4$
$\hat\beta_1 = \frac{-270\times15 + 3\times1430}{2400} = \frac{-4050+4290}{2400} = \frac{240}{2400} = 0.1$
住院天数 ≈ −4 + 0.1×心率(心率 70 → 3 天、90 → 5 天、110 → 7 天,全部吻合 ✓)
工程红线:实际中从不显式求逆!①$O(n^3)$ 慢;②特征共线时 $X^\top X$ 接近奇异,逆矩阵元素爆炸,解被舍入误差吞掉。正确姿势:QR/SVD 求解器;或岭回归(Ridge) $(X^\top X + \lambda I)^{-1}X^\top y$ —— 给对角线加 $\lambda I$ 强制可逆且压缩系数,这正是 L2 正则的代数真身(第 4 章的几何故事与这里互为表里)。
第 9 章

协方差矩阵:统计意义上的"特征一起动"

4.1 从患者队列到协方差矩阵

收集 $N$ 位患者(或 $N$ 个时刻)的中心化数据 $X \in \mathbb{R}^{N\times 3}$(每列均值已减为 0),协方差矩阵:

$$\Sigma = \frac{1}{N}X^\top X \in \mathbb{R}^{3\times 3}, \qquad \Sigma_{ij} = \frac{1}{N}\sum_n x^{(n)}_i x^{(n)}_j$$
  • 对角线 $\Sigma_{ii}$ = 特征 $i$ 的方差(该特征波动有多大);
  • 非对角 $\Sigma_{ij}$ = 特征 $i,j$ 的协方差(它们是否一起涨落)。当且仅当数据已按 z-score 标准化(中心化 且 每列标准差为 1,用总体标准差则配 $\frac1N$、样本标准差则配 $\frac1{N-1}$)时,$\Sigma$ 才恰好等于相关矩阵(对角线全 1,非对角 ∈ [−1,1])。仅中心化而未归一方差时,它只是协方差矩阵,相关系数要另算 $\rho_{ij} = \Sigma_{ij}/\sqrt{\Sigma_{ii}\Sigma_{jj}}$。
演算:4 位患者算血糖-心率相关性
中心化数据(均值 0,但方差未归一 —— 所以算的是协方差,相关要再除标准差):
P1(2.0, 1.5), P2(1.0, 1.0), P3(−1.0, −0.5), P4(−2.0, −2.0)
协方差:$\Sigma_{G,H} = \frac{1}{4}[2.0\times1.5 + 1.0\times1.0 + (-1.0)(-0.5) + (-2.0)(-2.0)]$
$= \frac{1}{4}[3.0 + 1.0 + 0.5 + 4.0] = \frac{8.5}{4} = 2.125$
方差:$\Sigma_{G,G} = \frac{1}{4}(4+1+1+4) = 2.5$;$\Sigma_{H,H} = \frac{1}{4}(2.25+1+0.25+4) = 1.875$
相关系数:$\rho = \frac{2.125}{\sqrt{2.5\times1.875}} = \frac{2.125}{2.165} = \mathbf{0.98}$ —— 强正相关:在该队列中,血糖高的患者心率普遍也快 ✓
现实意义:$\Sigma$ 是队列层面、统计层面的对象:它回答"在这群患者中,血糖和心率是否一起变化"。注意三个限定词 —— 队列(不是单个患者)、统计(不是因果)、线性(Pearson 只捕捉线性共变)。第 13 章你会看到,这三个限定词正是 attention 解读最容易越界的地方。另外,$X^\top X$ 这种"自身乘自身转置"的矩阵叫 Gram 矩阵,它必然对称半正定 —— 保证相关矩阵可以安全地做特征分解(下一章)。

4.2 相关 ≠ 因果:医疗数据的经典陷阱

例:队列中发现"使用胰岛素"与"死亡率"正相关。不是胰岛素致死,而是病情重的患者才用胰岛素(混杂因子:病情严重程度同时导致用药和死亡)。相关矩阵 $\Sigma$ 永远只能给你第一个层面的事实。因果推断需要随机对照试验、倾向评分、工具变量等另一套方法论。
第 10 章

特征值与 PCA:把患者队列画在一张图上

5.1 主成分 = 队列差异的"主轴"

对协方差矩阵做特征分解 $\Sigma = Q\Lambda Q^\top$:特征向量 $q_1$ 是患者之间差异最大的方向,特征值 $\lambda_1$ 是该方向上的方差大小。

演算:接上章,2×2 相关结构的特征分解
$\Sigma = \begin{pmatrix}2.5 & 2.125\\2.125 & 1.875\end{pmatrix}$,特征方程:$\lambda^2 - 4.375\lambda + (4.6875-4.5156) = \lambda^2 - 4.375\lambda + 0.172 = 0$
$\lambda_1 = 4.335$(占 99.1%),$\lambda_2 = 0.040$(占 0.9%)
主方向:$(\Sigma - 4.335I)q = 0 \Rightarrow q_1 \approx (0.76, 0.65)$ —— 血糖权重 0.76、心率权重 0.65 的组合方向
医学解读(带条件):PCA 能保证的只是:PC1 是该队列方差最大的方向,99% 的患者间差异沿它分布。至于它是不是"病情严重度",PCA 本身不知道 —— 只能说它构成一个候选的潜在严重度轴,必须额外验证(如计算 $\mathrm{corr}(PC1, \text{临床严重度/结局})$)才能下这个结论。把"最大方差方向"直接命名为临床概念,是 PCA 解读最常见的越界 ✓
交互演示:患者队列的 PCA 视图

每个点是一位患者(血糖-心率平面,已标准化)。调节"真实共变强度",观察 PC1(红箭头)如何旋转对齐数据主轴 —— 它找到的就是"患者差异最大的方向"。

现实意义:①论文里常见的"队列可视化图"(患者点云按结局着色,呈明显梯度)就是 PCA/t-SNE/UMAP 的产物 —— 其中 PCA 是唯一有严格线性代数解释的方法;②特征值衰减速度(谱)告诉你队列有几个独立的"变异模式":若前 2 个特征值占 95%,说明患者虽千差万别,本质上只沿 2 个轴变化;③这也解释了表征学习为什么可行:高维医疗数据的真实自由度(intrinsic dimension)远比 F 小。
第 11 章

SVD 奇异值分解:任何矩阵 = 旋转 × 拉伸 × 旋转

11.1 分解与最优低秩近似

$$A = U\Sigma V^\top$$ U、V 正交(旋转),Σ 对角(奇异值 $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$)。Eckart–Young 定理:只保留前 k 个奇异值,得到在所有秩-k 矩阵中误差最小的近似 $A_k = U_k\Sigma_kV_k^\top$。
对 EHR 的三层意义:①患者原型:对队列矩阵(患者×特征)做 SVD,若前 5 个奇异值占能量 95%,说明几千名患者本质上由 ~5 种"原型模式"混合而成 —— 表型分型(phenotyping)的代数基础;②压缩:低秩近似用 $k(m+n)$ 个数代替 $mn$ 个 —— 但注意:低秩 ≠ 隐私保护,$A_k$ 仍可能保留稀有患者的可重构信息,隐私场景必须另加去标识化/差分隐私/聚合机制;③Med2Vec/代码嵌入:诊断代码共现矩阵(类似 NLP 的 PMI 矩阵)做 SVD,就得到 ICD 代码的向量嵌入 —— 医疗表征学习的开山之作正是矩阵分解。
演算:2×2 的 SVD 全貌
$A = \begin{pmatrix}3&0\\0&1\end{pmatrix}$ 已是"拉伸"形:$U = I$,$\Sigma = \begin{pmatrix}3&0\\0&1\end{pmatrix}$,$V = I$
奇异值 3 和 1:血糖方向能量 3 倍于血压方向
秩-1 近似:$A_1 = 3\,u_1v_1^\top = \begin{pmatrix}3&0\\0&0\end{pmatrix}$ —— 扔掉 σ=1 的方向,保留 90% 能量($9/(9+1)$,能量 = 奇异值平方)。奇异值的相对大小 = 各方向信息量,小奇异值方向可以安全丢弃 ✓
与特征分解的关系:奇异值 = $\sqrt{A^\top A\text{ 的特征值}}$。对第 10 章的对称协方差矩阵,两者重合 —— PCA 就是协方差矩阵的特征分解,也可直接对数据中心化矩阵做 SVD 得到(数值上更稳,不求 $X^\top X$)。
通往 LoRA 的桥:SVD 说"大矩阵可由少量方向近似";LoRA 则把微调增量显式参数化为 $\Delta W = BA$(因此 $\mathrm{rank}(\Delta W)\le r$)—— 这是结构假设/归纳偏置,不是证明了"真实最优更新必然低秩"。第 20 章的医疗 LoRA 应用,理论根基就在这里。
第 12 章

Feature Attention 完整精算:特征之间如何"互相参考"

把 3 个特征当作 3 个 token 做自注意力。本章分两步:12.1 先用固定嵌入把计算机制算透;12.2 再建立真正依赖患者状态的严格框架 $X_p \to E_p \to Q_p,K_p \to A_p \to H'_p$ —— 你将看到,只有后者才配叫 patient-specific attention。

12.1 机制演算 · 第 1 步:特征嵌入与 Q/K/V 投影(教学版,嵌入先固定)
把三个特征的嵌入向量(各 2 维,由嵌入矩阵 $W_e$ 学得)排成矩阵:
E = [1 0] ← Glucose 的嵌入 [0 1] ← HR 的嵌入 [1 1] ← BP 的嵌入
投影(演示用矩阵):$W^Q = I$,$W^K = \begin{pmatrix}1&1\\0&1\end{pmatrix}$,$W^V = \begin{pmatrix}1&0\\0&2\end{pmatrix}$
$Q = EW^Q = E$;$K = EW^K = \begin{pmatrix}1&1\\0&1\\1&2\end{pmatrix}$;$V = EW^V = \begin{pmatrix}1&0\\0&2\\1&2\end{pmatrix}$
第 2 步:QKᵀ —— 原始注意力分数
$QK^\top = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}\begin{pmatrix}1&0&1\\1&1&2\end{pmatrix} = \begin{pmatrix}1&0&1\\1&1&2\\2&1&3\end{pmatrix}$
第 i 行第 j 列 = 特征 i 的 Query 与特征 j 的 Key 的点积 —— "i 想从 j 那里取多少信息"的原始分
缩放(÷√d_k = √2 ≈ 1.414)后逐行 softmax:
$A = \begin{pmatrix}0.40&0.20&0.40\\0.25&0.25&0.50\\0.28&0.14&0.58\end{pmatrix}$ (每行和为 1)
第 3 步:逐行解读(这是论文分析的标准句式)
第 1 行(血糖):$\text{new Glucose} = 0.40\,V_G + 0.20\,V_H + 0.40\,V_B$
→ 更新血糖表征时,血糖/心率/血压各自 value 向量的聚合权重为 0.40 / 0.20 / 0.40
第 3 行(血压):$\text{new BP} = 0.28\,V_G + 0.14\,V_H + 0.58\,V_B$
→ 血压表征中,自身 value 的聚合权重最大(0.58),血糖 value 次之(0.28)
⚠ 措辞红线:$A_{ij}=0.7$ 只能说"$v_j$ 的聚合权重为 0.7",不能说"70% 的信息来自特征 j" —— 最终表征中各来源的实际贡献还取决于各 $v_j$ 的方向、模长以及彼此间的抵消/增强。权重 ≠ 信息贡献占比。
第 4 步:H′ = AV,以血压行为例:
$h'_B = 0.28(1,0) + 0.14(0,2) + 0.58(1,2) = (0.86, 1.44)$
新向量已不再是"纯血压",而是融合了血糖与心率上下文的 contextual representation ✓
核心公式再强调(严谨版):$$A_{ij} = \text{特征 }i\text{ 更新自身表征时,对特征 }j\text{ 的 value 向量 }v_j\text{ 施加的聚合权重}$$行 = 接收方(query),列 = 提供方(key/value)。行和为 1,列和没有任何约束 —— 某特征可以"被所有人参考"(列和大),这不违反任何规则。它是 $h'_i = \sum_j A_{ij}v_j$ 里的加权系数,不是信息占比、不是相关、更不是因果。
12.1 的故意留白:上面的 $E$、$W^Q$、$W^K$、$W^V$ 全是固定矩阵,因此算出的 $A$ 对所有患者都相同 —— $A_{P1} = A_{P2}$。它可以教机制,但不能作为 patient-specific interaction 的证据。真正的个体化交互必须让嵌入依赖患者状态,见 12.2。

12.2 严格框架:让 E_p 依赖患者状态,$A_{P1}\neq A_{P2}$ 才真正成立

patient-specific attention 的逻辑链必须是:患者状态不同 → 特征 token 嵌入不同 → Q/K 不同 → A 不同。断掉任何一环,"个体化交互"就是空话。一种最小实现:基础嵌入按该患者该特征的标准化取值缩放 —— $e_{p,i} = (1+\tfrac12 x'_{p,i})\cdot e^{base}_i$(缩放因子 $\alpha_i = 1+\tfrac12 x'_i$,保证非负且随异常程度放大)。

第 1 步:两位患者 → 两个不同的嵌入矩阵
患者 P1(休克前期)x' = (2.0, 1.5, −1.0):缩放因子 $\alpha = (2.0,\ 1.75,\ 0.5)$
E_P1 = [2 0 ] ← 2.0 × (1,0) Glucose [0 1.75] ← 1.75 × (0,1) HR [0.5 0.5 ] ← 0.5 × (1,1) BP
患者 P2(稳定期)x' = (0.2, 0.0, 0.4):$\alpha = (1.1,\ 1.0,\ 1.2)$
E_P2 = [1.1 0 ] [0 1 ] [1.2 1.2]

第 13 章

四概念辨析:论文写作的红线

这是本教程最重要的一章。四个概念在数学上是四个不同的对象,但论文里经常被混用:

① Feature Weight(特征权重)

w_i ∈ R, 标量/向量

回答:"这个特征本身有多重要?"
形态:一个向量 $w = [0.6, 0.3, 0.1]$,每个特征一个数。
来源:特征重要度、注意力池化权重、SHAP、排列重要性。

② Feature Attention(特征注意力)

A_ij, 方阵(每行和为1)

回答:"特征 i 更新自己时,对特征 j 的 value 施加多大聚合权重?"
形态:$h'_i=\sum_j A_{ij}v_j$ 中的加权系数;逐患者的(仅当嵌入依赖患者状态,见 12.2)、上下文化的。
本质:$\mathrm{softmax}(QK^\top/\sqrt d)$,是表征构建机制;权重 ≠ 信息贡献占比。

③ Correlation(统计相关)

corr(x_i, x_j) ∈ [-1,1]

回答:"队列中两个特征是否一起变化?"
形态:协方差矩阵归一化,队列级、对称、无方向。
来源:第 9 章的 $\Sigma$,纯统计对象,与模型无关。

④ Causality(因果关系)

do(x_i) → x_j ?

回答:"干预特征 i 是否会改变特征 j?"
形态:结构因果模型 / 干预分布。
来源:随机对照试验、因果推断框架 —— observational 数据 + 任何矩阵都算不出来。

对照演算:同一批数据,四个对象各是什么
Attention(患者 P1):$A^{P1}_{G,H} = 0.7$ —— "更新 P1 的血糖表征时,心率 value 的聚合权重为 0.7"(个体、有方向、机制性;不是"70% 信息来自心率")
Correlation(整个队列):$\rho_{G,H} = 0.98$ —— "队列中血糖与心率强正相关"(群体、对称、统计性)
Feature weight:$w_G = 0.6$ —— "对预测任务,血糖贡献最大"(任务相关,无方向)
Causality:以上三个都无法回答"降低心率能否降低血糖" —— 需要干预数据 ✓
论文红线(checklist):
  • ❌ "The attention weight 0.7 indicates a strong medical correlation between glucose and HR" —— 越界,attention 不是相关;
  • ❌ "The model discovers that HR causes glucose elevation" —— 严重越界;
  • ✅ "The model learns to aggregate 70% of HR's information when constructing P1's glucose representation, suggesting learned feature interactions for this patient subgroup";
  • ✅ 想加强论证:补充 attention 权重与 Pearson 相关的一致性分析、临床医生盲评、消融实验(去掉高 attention 边,性能下降多少);
  • ✅ Attention 可视化应作为 case study / interpretability analysis,而不是主要结论证据("Attention is not Explanation" — Jain & Wallace 2019,值得引用并回应)。
但也不要因噎废食:Attention 对表征学习的价值是实打实的 —— $H' = AV$ 让每个特征的表征融合了上下文,这正是 Transformer 在 EHR 上打败"逐特征独立编码"的原因。把它当作机制陈述,不要当作医学发现陈述。

Patient-specific 交互:你研究中最有价值的观察点

8.1 不同患者,不同的 A 矩阵

当且仅当 $E_p$ 依赖患者 $p$ 的状态(12.2 的严格条件)时,$Q_p = E_p W^Q$、$K_p = E_p W^K$ 才随患者变化,注意力矩阵才真正个体化:$A_{P1} \neq A_{P2}$。以下数字全部来自 12.2 的完整推导,不是示意值。

对照:同一对特征,不同患者的聚合权重(接 12.2 的实算)
患者 P1(休克前期,x' = (2.0, 1.5, −1.0)):$A^{P1}_{H,G} = 0.49$ —— 更新心率表征时,血糖 value 的聚合权重近一半;反向 $A^{P1}_{G,H} = 0.05$,极弱。交互是有方向的,两个方向可以悬殊
患者 P2(病情稳定,x' = (0.2, 0.0, 0.4)):$A^{P2}_{H,G} = 0.23$,$A^{P2}_{G,H} = 0.17$ —— 双向都弱且接近对称,两特征基本各自表征

8.2 一个重要区分:Importance 与 Interaction 不矛盾

对同一患者可以同时成立:"血糖是最重要的变量"(feature importance 高) 且 "血糖表征对心率 value 的聚合权重高"(interaction 高)。前者讲"预测时看谁",后者讲"构建表征时给谁的 value 多大权重"。论文中应作为两个并行的分析维度呈现:一个 $F$ 维向量 + 一个 $F\times F$ 矩阵。

14.3 从观察到研究问题的三步

  1. 聚类 A 矩阵:收集全队列的 $\{A_p\}$,向量化后聚类 → 若簇与临床亚型吻合,说明模型学到了有医学意义的交互亚型;

第 15 章

多头注意力、位置/时间编码与 KV Cache

15.1 多头:多组矩阵,各看一种交互模式

把 d 维嵌入切成 h 份,每份独立做第 12 章的计算,再拼接投影:

$$\mathrm{MultiHead}(X) = \mathrm{Concat}(head_1,\dots,head_h)\,W^O$$
医疗解读:单个注意力矩阵 $A$ 是"平均化"的交互;多头允许模式分工 —— head 1 学会盯"血糖↔心率"代谢耦合,head 2 盯"血压↔心率"循环耦合,head 3 盯时间模式。这也是第 20 章避坑清单里"不要平均所有头再解读"的原因:平均会抵消分工(一头 +0.8 一头 −0.8,均值 ≈ 0,但两个头各自都有强模式)。论文应逐头可视化,并报告头间一致性。

15.2 位置编码与它的医疗变体

  • 问题:注意力对 token 顺序天然不敏感(矩阵乘对行排列等变),但病程里"谁先谁后"是核心信息;
  • 正弦编码:$\mathrm{PE}(pos,2i)=\sin(pos/10000^{2i/d})$ —— 给每个时刻加一组多频率正弦指纹;
  • RoPE:用旋转矩阵(第 6 章已验算其保长性)按位置旋转 Q/K 向量,使点积 $q_m^\top k_n$ 只依赖相对距离 $m-n$;
  • 医疗版:把"第几个小时"换成不规则的 $\Delta_t$(距上次测量的真实小时间隔)做 Time2Vec/正弦编码 —— 位置编码的思想 + 不规则采样的现实(第 16 章)。

15.3 KV Cache:ICU 实时监测的矩阵记忆

流式推理(每来一条新测量就更新风险分)时,过去 T 个时刻的 K、V 不变 —— 缓存成 $K_{cache} \in \mathbb{R}^{T\times d}$、$V_{cache}$,新时刻只需为新 query 计算 $q_{new}K_{cache}^\top$(一行分数,约 $O(Td)$)与一行加权和。不缓存时,每一步都要对整个前缀重算 K/V 投影及注意力,单步成本随 T 增长,累计生成 T 步的注意力总量呈二次量级 —— 所以省的是重复计算,而不是把单步从 $O(T^2)$ 变 $O(T)$ 这么简单。这是对注意力矩阵结构的纯工程利用:理解"行=query、列=key"的不对称性,才能看懂为什么 K/V 可缓存而 Q 只来新的。

16.4 RNN:同一个矩阵连乘 T 次

RNN 的隐状态 $h_t = \tanh(Wh_{t-1} + Ux_t)$(记 $z_t = Wh_{t-1} + Ux_t$)。对相隔 $t$ 步的两个隐状态,由链式法则(第 17 章):$$\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^{T} \frac{\partial h_k}{\partial h_{k-1}} = \prod_{k=t+1}^{T} D_k\, W,\qquad D_k = \operatorname{diag}\big(1-\tanh^2(z_k)\big)$$注意:这里出现的是 矩阵连乘(矩阵幂 $W^{\,t}$,指数 $t$ = 时间步数),不是转置 $W^\top$ —— 记号上极易混淆,含义完全不同。诊断性分析中,若各 $D_k$ 的缩放接近 1 且 $W$ 可对角化 $W = Q\Lambda Q^{-1}$,则连乘的主项 $\sim Q\Lambda^{\,t}Q^{-1}$,衰减/放大速率由主特征值 $\lambda_1$ 主导:

演算:梯度消失/爆炸的定量演示(主特征值近似)
若主特征值 $\lambda_1 = 0.9$:48 小时后梯度贡献 $\sim 0.9^{48} \approx 0.006$ —— 入院时的危急值对预测几乎零影响(梯度消失)。再乘上 $D_k$ 的 tanh 导数($\le 1$,饱和区趋近 0),实际衰减只会更快
若 $\lambda_1 = 1.05$:$1.05^{48} \approx 10.4$ —— 每步放大,几十步后溢出(梯度爆炸)
医疗含义:ICU 里 48 小时前的异常恰恰可能是病因线索。LSTM/GRU 用门控(逐元素乘 sigmoid 门,梯度路径上出现的是接近恒等的对角阵而非 $W$ 的连乘)缓解这一问题;RETAIN/Transformer 用注意力让任意时刻直接相互作用 —— 本质是把梯度的计算依赖路径从 $O(T)$ 步缩短到 $O(1)$ 步($h'_t$ 一步之内直接依赖所有 $v_j$,不再经过 $T$ 次 Jacobian 连乘),长程梯度信号因此不再被指数级衰减 ✓
第 17 章

梯度、Jacobian、Hessian 与反向传播:模型如何"学"

17.1 梯度:风险曲面上升最快的方向

对标量损失 $L(\mathbf{w})$,$\nabla L = (\partial L/\partial w_1, \dots)^\top$ 是向量:方向 = 上升最快,模长 = 速率。训练 = 反着它走:$w \leftarrow w - \eta\nabla L$。

演算:二次碗上的一步下降
$L(w_1,w_2) = w_1^2 + 3w_2^2$,$\nabla L = (2w_1, 6w_2)$。在 (1,1):$\nabla L = (2,6)$ —— $w_2$ 方向陡 3 倍(碗在该方向更窄)
η=0.1 一步:$(1,1) \leftarrow (1,1) - 0.1(2,6) = (0.8, 0.4)$,L 从 4 降到 $0.64+0.48 = 1.12$ ✓

17.2 Jacobian 与 Hessian:一阶导与曲率

对象形状患者建模中的作用
梯度 ∇L向量SGD/Adam 的更新方向
Jacobian $J_{ij}=\partial f_i/\partial x_j$矩阵每层的局部导数;反向传播 = 向量-Jacobian 积(VJP)沿计算图连乘
Hessian $H_{ij}=\partial^2 L/\partial w_i\partial w_j$对称矩阵(要求 $L$ 二阶连续可微,$C^2$ 条件下才有 $H_{ij}=H_{ji}$)曲率:在驻点($\nabla L=0$)处,正定 ⇒ 严格局部极小;特征值有负有正 ⇒ 鞍点;半定($\lambda_{\min}=0$)⇒ 二阶检验失效;条件数大 = 又窄又深的峡谷,梯度下降震荡(见下方演示)
两个常见误用的反例:① $L(x)=x^3$ 在 $x=0$ 处 $L''=0$(半定)但不是极值点 —— "特征值非负"不构成极小的充分条件;② 反过来,非驻点处 Hessian 正定什么也说明不了(此时下降方向仍由 $\nabla L$ 决定)。因此正确表述是:驻点 + 正定 ⇒ 严格局部极小,其它情况单独讨论。
鞍点直觉:一个常被引用的启发式说法是"高维损失面上鞍点远多于局部极小"——直觉是:要让驻点成为极小,需要 Hessian 的全部 $n$ 个特征值同时为正;维度越高,"全体为正"越难满足,随机景观理论(Dauphin et al., 2014 等对高斯随机场的 Kac-Rice 分析)确实给出指数级悬殊的计数。但注意这是对理想化随机损失面的渐近结果,不是对具体网络的定理,更不存在"概率恰为 $1/2^n$"这样的精确结论。实践要点:动量(momentum)靠惯性冲出鞍部平台;二阶方法太贵,一阶 + 噪声通常足够逃逸。医疗小模型(逻辑回归 + 交叉熵)的损失对线性 score 是凸的碗面 —— 严格说:共线特征或数据完全可分时是非严格凸(Hessian 半正定,解不唯一或不可达有限值),但不存在坏的局部极小 —— 这也是为什么逻辑回归至今是临床基线:优化上它"没有惊喜"。

17.3 链式法则 = 反向传播的全部内容

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z}\cdot\frac{\partial z}{\partial y}\cdot\frac{\partial y}{\partial x}$$
演算:最小网络的一次前向 + 反向(2 输入 → 2 隐藏 ReLU → sigmoid 输出恶化风险)
参数:$W^{[1]} = \begin{pmatrix}0.5&0.3\\-0.2&0.8\end{pmatrix}$, b⁽¹⁾=(0.1, 0.1);$W^{[2]} = (0.6, -0.4)$;输入 x=(1.0, 0.5)(标准化血糖、心率),标签 y=1(72h 内恶化)
前向①:$z^{[1]} = W^{[1]}x + b^{[1]}$:$z_1 = 0.5+0.15+0.1 = 0.75$;$z_2 = -0.2+0.4+0.1 = 0.30$;ReLU → $a^{[1]} = (0.75, 0.30)$
前向②:$z^{[2]} = 0.6\times0.75 - 0.4\times0.30 = 0.33$;$\hat y = \sigma(0.33) = 0.5817$;交叉熵 $L = -\ln 0.5817 = 0.5418$
反向①(sigmoid+交叉熵的极简梯度):$\partial L/\partial z^{[2]} = \hat y - y = -0.4183$
反向②(梯度 = 误差 × 输入的外积):$\partial L/\partial W^{[2]} = -0.4183\times(0.75, 0.30) = (-0.3137, -0.1255)$

全链路演算(数字接第 12、16 章)
① 标准化(第 7 章):原始 (250,120,90) → (2.17, 1.75, −1.00)
② 特征嵌入:投影到嵌入空间,得 E(第 12 章的起点)

19.1 softmax 减最大值:注意力矩阵不溢出的前提

演算:溢出 vs 稳定

19.2 条件数:共线特征的误差放大器

$\kappa(A) = \sigma_{max}/\sigma_{min}$。κ 大 ⇒ 输入的微小误差被放大 κ 倍进解里。

医疗高发场景:①检验指标高度共线(第 8 章肌酐/eGFR 例)→ 正规方程 $(X^\top X)\beta = X^\top y$ 的 κ 被平方放大 —— 所以永远用 QR/SVD 求解,或岭回归加 $\lambda I$;②未标准化特征(血糖上百 vs 体温三十几)→ 损失面 Hessian 条件数巨大 → 第 17 章演示里的"之字形"震荡。标准化、LayerNorm 的本质都是缩小等效条件数。

19.3 log 域计算:轨迹概率不“下溢”的前提

演算:连乘概率下溢
患者 100 个时刻的联合似然 $= \prod_t p_t$,即使 $p_t = 0.9$:$0.9^{100} \approx 2.7\times10^{-5}$,再乘几百个就到 $10^{-300}$ 以下 → float64 下溢为 0,loss = −ln 0 = inf 💥
解:$\ln L = \sum_t \ln p_t$ —— 乘变加,永远在 log 域相加,最后需要时才 exp 回来。交叉熵、负对数似然、beam search 全部 log 化 ✓
调试口诀:loss 变 NaN 时按序排查 —— ①学习率(第 17 章发散)→ ②softmax/exp 溢出(19.1)→ ③log(0) 或除 0(19.3,掩码位是否参与平均)→ ④梯度爆炸(第 4 章裁剪)。医疗数据多一条:⑤检查极端误录值(血糖 9999)是否进了一个 batch。
第 20 章

低秩微调医疗大模型 + 论文避坑清单

20.1 LoRA:用低秩参数化适配医疗领域

通用大模型权重 $W_0$ 冻结,只学 $\Delta W = BA$(其中 $B\in\mathbb{R}^{d\times r}, A\in\mathbb{R}^{r\times d}$,秩 $r\ll d$)。注意措辞:这是把更新显式参数化为低秩形式($\mathrm{rank}(\Delta W)\le r$ 由构造保证),是一个结构假设 / 归纳偏置,而不是"证明了最优更新必然是低秩的"——后者只在部分理论结果和实验观察中有支持。医疗场景的特殊动机:

  • 患者隐私:可训练参数大幅缩减(典型为全量的千分之几到百分之几,取决于秩 $r$、目标模块数量与底座规模——下方示例是 3.1%;常见的"0.1%–1%"说法对应更大的底座或更小的 $r$,不是普适数字),可在院内单机微调,原始数据不出院;
  • 小数据:罕见病队列可能只有几百例,全量微调必过拟合,低秩约束是天然的归纳偏置;
  • 多中心:每个医院一个 LoRA 适配器,共享底座 —— 联邦学习的轻量化版本。
演算:EHR Transformer 一层(d=512)的 LoRA 参数量
全量:$512\times512 = 262{,}144$;LoRA(r=8):$512\times8 + 8\times512 = 8{,}192$ —— 3.1% ✓
直觉:领域适配所需的"新方向"少(医学概念大多已在通用语料中学过,只需校准到 EHR 的表达习惯),低秩假设在医疗域特别合理。
